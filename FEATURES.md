# Features

## PQC Remediation
Suggests post-quantum migration options for vulnerable findings, including hybrid (classical + post-quantum) and full-migration paths. Outputs a PR description and reviewer checklist. Nothing is applied automatically.

## Mosca HNDL Timeline
Shows which assets are at risk from "harvest now, decrypt later" attacks, using a range of Q-Day estimates. Adjustable migration time lets you see how the risk window changes.

## Compliance & CBOM Reports
Generates a Cryptographic Bill of Materials (CycloneDX) and compliance coverage against NIST SP 800-53 and CNSA 2.0. Export as PDF, CSV, or a ZIP evidence bundle.

## Dashboard
Overview of findings, readiness score, and an interactive topology graph.
